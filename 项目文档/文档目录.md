# 项目文档目录

## 目录结构

1. `实验报告/`
   - `实验报告.md`：报告正文源文件
   - `实验报告.html`：便于本地预览的导出版本
   - `实验报告.pdf`：最终提交版
   - `导出报告.py`：将 Markdown 导出为 HTML 的脚本
   - `生成反AI截图素材.py`：从运行中的系统抓取反 AI 审查卡片 HTML
   - `截图/`：报告中引用的所有截图素材
2. `答辩材料/`
   - `答辩对照清单.md`
   - `答辩话术.md`
   - `验收checklist.md`
3. `其他资料/`
   - `用户日常登录.txt`

## 说明

本目录专门存放课程交付相关的文档与截图，不与 `webapp/`、`oj_judge/` 等源码目录混放，便于答辩、查阅与归档。

  我是朋友，第一次玩怎么用？  ——  DeiDei 叠叠对战（新手版 2 分钟上手指南）
========================================================================

★★ 3 步打开游戏 ★★

  第 1 步：你收到我发的压缩包，解压到一个文件夹（任意位置都行）
         解压后文件夹里应该能看到：
           - DeiDei启动.bat    ← 双击这个启动（以后每次玩都双击它）
           - gui_deidei.py / deidei_env.py / rl_ai.py / deidei_gym_env.py
           - requirements_rl.txt
           - rl_checkpoints / latest.zip   ← 这个文件要在，"专家 AI"才能用！

  第 2 步：首次安装（只做一次，以后秒跳过）
         双击 DeiDei启动.bat，黑框会显示"首次启动正在安装依赖..."
         （没装 Python 3.10+ 的朋友先去 https://www.python.org/downloads/ 装，
          安装时记得勾 "Add Python to PATH"！）
         依赖安装 1~3 分钟，装完自动启动 GUI。

  第 3 步：以后每次玩 → 双击 DeiDei启动.bat → GUI 自动弹出。


★★ 新手 2 分钟正式上手（游戏界面从左到右 3 块）★★

  ■ 顶栏"设置"：
     AI 对手难度  ▼
       简单 AI   ← 新手就选这个，它会犯很多错，你随便打练手
       普通 AI（近似 GTO）= 每回合按"无剥削均衡混合策略"出招，
                         你很难剥削它，它也不会剥削你，新手进阶用
       专家 AI（RL 853 万步训练）= 最强，用自博弈训练 853 万步的模型
                                   接近人类顶级水平
     普通 AI 精度（GTO 迭代次数）▼
       快速 2 秒 / 标准 5~8 秒（推荐默认）/ 高 15~30 秒
     专家 AI 推理线程  ▼
       省电（CPU 占用低）/ 平衡（默认）/ 极速（拉满多核）

     点【开始新对局】就可以开始啦！

  ■ 左下方"你要出什么"：
     每个按钮 = 一招。按钮下写了它的 DD 消耗。
     ★ 划重点！新手忘不掉的两个交互：
       左键点按钮  = 出这招
       右键点按钮  = 弹这招的详细说明（作用/克什么/被什么克/新手坑）
       （Mac / 没右键？ 按 鼠标中键 也行）
     不懂哪个招就右键点它！推荐第一次玩 每个按钮都右键看一遍，15 分钟全懂。

  ■ 右下方"对局记录 / 新手提示"：
     这里写了每回合你和电脑出什么、DD 变化、胜负判定、新手提示。
     下方 2 个按钮：
       【查看当前局面你的 GTO】= 给你这一局面的近似无剥削均衡出招概率+参考胜率，
                           你纠结要不要出田立军挡大 Bi 时就点这个！
       【输入任意状态查询 GTO】= 自己填双方 DD / 炸药层 / 雷电层 / 聂湘充能 等，
                           自己研究某局面怎么玩。


★★ 新手最容易搞混的 5 条（记不记都行，错几局就懂了）★★

  ❌ 错 1：大落后（0 DD vs 5 DD）狂点"防御"
     → 防御只能挡 普通削 + Bi，Pragon/三雷/沃尔沃/大Bi 全挡不住！
        要补田立军 + 合法的 4 个专属防御。

  ❌ 错 2：4 个专属防御（Pragon防 / 沃尔沃防 / 三雷防 / 聂湘防）当通用防
     → 它们连 Bi 都挡不住！没对应攻击时 = 严格劣于防御，电脑会自动 ban。

  ❌ 错 3：田立军 vs 反弹 / 吸收 / 云
     → 田立军方 直接输！最反直觉的 1 条，务必背下来。

  ❌ 错 4：炸药延迟 A→B→C，以为要等 3 回合
     → 现在改了：B 回合末就进炸药层，T 出炸药 → T+2 初就能出炸药·Pragon。

  ❌ 错 5：张新伟复制 A + 接着出 A，对手放历强
     → 两招实际连续等效，历强触发，你直接输。


★★ 3 种"怎么玩才能赢"的思路（新手 → 高手进阶）★★

  ① 打简单 AI：
     观察它的坏习惯（比如反射率过高、落后不出专属防御），用反制招剥削它，
     削 + Bi + Pragon 连招随便赢。

  ② 打普通 AI（GTO）：
     点【查看当前局面 GTO】按给的概率混合出招，长期不会输。
     新手练手神器，练熟了再打专家 AI。

  ③ 打专家 AI（RL 853 万步）：
     这个最强，它自带人类专家规则（落后保底、连招 boost、反射上限...），
     赢它靠博弈直觉 + 观察它的习惯 + 自己创造 exploit 点。


★★ 给朋友的小彩蛋 ★★

  ✅ 大落后（0 vs 5DD）防御策略符合人类直觉，不会被大 Bi / Pragon 剥削
  ✅ 对手没攻击能力的时候电脑不会乱出反弹送人头
  ✅ GUI 新手友好（右键查招说明 / 规则手册 7 大板块 / 难度带中文说明 /
     精度带说明 tooltip）

  玩得开心 :)  有 bug 直接把报错截图 / 复现步骤发给我就好！
